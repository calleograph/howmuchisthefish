# Обновление

## Через веб-интерфейс (рекомендуется)

**Настройки → Обновление системы** показывает текущую и доступную версию,
список изменений и кнопку запуска. Этапы обновления отображаются по мере
выполнения: проверка версии → резервное копирование → загрузка образов →
применение миграций → перезапуск контейнеров → проверка работоспособности.

Обновление выполняет системная служба на хосте (root-helper) — сам
контейнер приложения не имеет доступа к Docker и не может сам себя
перезапустить, см. [ARCHITECTURE.md](ARCHITECTURE.md#обновление). Перед
применением миграций автоматически создаётся резервная копия; если
миграция или проверка после обновления не проходит — происходит
автоматический откат к предыдущей версии.

## Вручную, из командной строки

```bash
cd security-awareness-platform
git fetch --tags
git checkout v0.2.0   # нужная версия
cd deployment
docker compose pull   # если используете готовые образы из GHCR
docker compose build  # либо пересоберите из исходников
docker compose run --rm backend npx prisma migrate deploy
docker compose up -d
```

## Перед обновлением

- Резервная копия создаётся автоматически при обновлении через веб-интерфейс.
  При ручном обновлении создайте её сами:
  `./scripts/backup.sh --label pre-update` (см. [BACKUP_RESTORE.md](BACKUP_RESTORE.md))
- Прочитайте [CHANGELOG.md](../CHANGELOG.md) для целевой версии — там
  отмечены несовместимые изменения, если они есть

## Если обновление не удалось

Автоматическое обновление через интерфейс откатывается само при сбое
миграции или health-проверки. При ручном обновлении:

```bash
cd deployment
docker compose down
git checkout <предыдущий-тег>
docker compose build
docker compose up -d
# БД откатывать миграции вручную Alembic-подобным downgrade НЕ предполагается —
# восстановите из резервной копии, сделанной перед обновлением:
../scripts/restore.sh <путь-к-резервной-копии>
```

## Канал обновлений

В текущей версии (0.1.0) поддерживается один канал — стабильные релизы из
тегов `vX.Y.Z`. Выбор канала (stable/beta) из интерфейса планируется для
будущих версий, в 0.1.0 отсутствует — см.
[FEATURE_MATRIX.md](FEATURE_MATRIX.md).
