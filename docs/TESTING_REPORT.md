## Найденные и исправленные баги (по ходу тестирования)

1. **Массовая деактивация не работала** (`POST /employees/bulk/deactivate` перехватывался маршрутом `:id/deactivate`). Исправлен порядок объявления маршрутов.
2. **Лимит повторов очереди не применялся** на уже созданной очереди: `createQueue` идемпотентен и не обновляет существующую. Теперь `retryLimit`/`retryBackoff` передаются на каждую задачу.
3. **Отступы и тап-цели интерфейса** вне принятой шкалы: вкладки, поля ввода, выпадающие списки (см. ниже).

## Ограничения, которые не закрыты в этой итерации

- Нет реального SMTP-получателя на стенде: доставка писем (пп. 11, 15, 16 в части доставки) не подтверждена, только путь ошибок и повторов.
- Нет публичного домена: выпуск TLS-сертификата (п. 3) и позитивная DNS-верификация (п. 2) не проверены.
- Нет эндпоинта удаления кампаний (п. 23).
- Восстановление из резервной копии (п. 24) не проверено.
- Общие пункты §10 (персоны, user journeys, доступность с клавиатуры, экраны за пределами перечисленных) проверены частично.
