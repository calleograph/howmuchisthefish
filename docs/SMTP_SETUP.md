# Настройка исходящей почты

Платформа не включает собственный почтовый сервер — письма кампаний
отправляются через SMTP-релей вашей организации. Это упрощает установку и
избавляет вас от необходимости следить за репутацией IP-адреса и
DNS-записями (SPF/DKIM/DMARC) отдельного сервера рассылок: письма уходят
через уже доверенный корпоративный канал.

## Настройка через веб-интерфейс

**Настройки → Новое подключение**:

| Поле | Описание |
|---|---|
| Название | Произвольное имя для различения нескольких подключений |
| Хост | Адрес SMTP-сервера |
| Порт | Обычно `587` (STARTTLS) или `465` (неявный TLS) |
| TLS/STARTTLS | Включено по умолчанию — выключайте только для тестовых серверов в закрытой сети |
| Пользователь / Пароль | Данные для аутентификации на SMTP-сервере (опционально — некоторые релеи в закрытой сети не требуют) |
| Адрес отправителя | From-адрес писем кампании |

После сохранения нажмите **Тест** и укажите адрес для проверочного письма —
платформа реально подключается к серверу (`SMTP VERIFY`) и отправляет
письмо, результат показывается сразу.

## Примеры распространённых провайдеров

### Office 365 / Exchange Online

- Хост: `smtp.office365.com`, порт `587`, TLS/STARTTLS включён
- Потребуется учётная запись с правом отправки (обычная или служебная)

### Google Workspace

- Хост: `smtp.gmail.com`, порт `587`
- Потребуется [пароль приложения](https://support.google.com/accounts/answer/185833), не основной пароль аккаунта

### SendGrid / Mailgun / Amazon SES

- Хост и порт — по документации провайдера (обычно `587`)
- Пользователь — специальный API-ключ или SMTP-логин провайдера, не ваш email

### Внутренний корпоративный релей

- Если релей разрешает отправку только с определённых IP, добавьте сервер
  платформы в список разрешённых
- Если используется самоподписанный сертификат — платформа **не** отключает
  проверку сертификата по умолчанию (`rejectUnauthorized: true`); для таких
  серверов обратитесь к администратору вашего релея за правильным
  сертификатом или промежуточным CA, доверие к самоподписанным сертификатам
  в текущей версии не настраивается через интерфейс

## Ограничение скорости отправки

Каждая кампания имеет свой параметр "писем в минуту" (по умолчанию 10) —
задаётся при создании кампании, чтобы не превысить лимиты вашего
SMTP-релея и не создать нагрузку, похожую на спам-рассылку.

## Домены получателей

Опционально можно ограничить кампанию списком разрешённых доменов
получателей — сотрудники с email вне списка не получат письмо, даже если
были включены в выбранную группу. Полезно, если группы пересекаются с
внешними подрядчиками.
