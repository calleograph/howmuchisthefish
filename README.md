# HowMuchIsTheFish

Открытый self-hosted инструмент для контролируемых учебных фишинговых
рассылок, проверки осведомлённости сотрудников и оценки устойчивости к
социальной инженерии. Устанавливается на собственный сервер организации.

## Возможности

- Импорт сотрудников из CSV, группы, массовое назначение
- Визуальный MJML-редактор почтовых шаблонов с персонализацией
- Конструктор учебных страниц с безопасным отслеживанием отправки форм —
  **значения, введённые сотрудником, никогда не покидают его браузер**:
  фиксируется только факт отправки, не логин/пароль
- Полный жизненный цикл кампании: подготовка → планирование → запуск →
  отслеживание (открытия, переходы, отправки форм) → отчёт
- Аналитика по сотрудникам, группам, кампаниям с экспортом в CSV
- Поддержка собственного SMTP-релея организации (встроенный почтовый сервер
  не требуется)
- OIDC и SAML для входа через корпоративный каталог
- Резервное копирование и обновление из веб-интерфейса

## Быстрый старт

```bash
git clone <url-репозитория> howmuchisthefish
cd howmuchisthefish
./scripts/install.sh
```

Подробности — [INSTALL.md](docs/INSTALL.md). Системные требования —
[SYSTEM_REQUIREMENTS.md](docs/SYSTEM_REQUIREMENTS.md).

NestJS (backend) · React + Vite (frontend) · PostgreSQL · pg-boss (очереди) ·
Docker Compose · Caddy (автоматический HTTPS).

## Важное предупреждение

Этот инструмент предназначен **исключительно** для авторизованного обучения
собственных сотрудников организации. Используйте его только с явного
разрешения руководства вашей организации и в рамках согласованной программы
повышения осведомлённости о фишинге. Использование против людей без их
ведома и вне рамок такой программы может быть незаконным.
