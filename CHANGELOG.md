## [0.1.0] — первый выпуск

Первая рабочая версия Security Awareness Platform — платформы для
контролируемых учебных фишинговых рассылок.

### Добавлено

- Управление сотрудниками: ручное создание, импорт из CSV с построчной
  валидацией, группы
- Почтовые шаблоны на основе MJML с переменными персонализации
- Учебные страницы с безопасным отслеживанием отправки формы — значения,
  введённые сотрудником, никогда не сохраняются на сервере
- Полный жизненный цикл кампании: создание, планирование, запуск, пауза,
  завершение
- SMTP-подключения с шифрованием пароля и проверочной отправкой
- Отслеживание событий: открытие письма, переход по ссылке, отправка формы,
  с классификацией подозрительных автоматических событий
- Аналитика по кампаниям, сотрудникам, группам с экспортом в CSV
- Установка одной командой (`scripts/install.sh`) на чистый Ubuntu/Debian
  сервер, два варианта публикации (встроенный HTTPS через Caddy или за
  внешним reverse proxy)
- Резервное копирование и восстановление с шифрованием архива
- Root-helper для безопасного обновления без прав Docker у контейнера
  приложения

### Известные ограничения

См. [docs/FEATURE_MATRIX.md](docs/FEATURE_MATRIX.md) — полный честный
список того, что реализовано и проверено, что реализовано, но не
проверено, и что отложено на будущие версии. В частности: визуальный
drag-n-drop редактор писем и страниц отложен (текстовый MJML/HTML-редактор
в этой версии), UI-поток входа через OIDC/SAML не реализован (переменные
окружения подключены, но без экрана входа), обновление через веб-интерфейс
не реализовано (есть командная строка).
